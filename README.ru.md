# AniHako

Веб-приложение для аниме на базе публичного API [YummyAnime](https://yani.tv).
Один фронтенд закрывает почти всё, что может понадобиться фанату: каталог с
поиском, встроенный плеер, личные списки со статистикой, друзья — и несколько
ништяков вроде свайпера, турнира и тир-листа, чтобы просто побаловаться с
уже просмотренным.

Интерфейс **пока только на русском** (английский в планах), адаптируется под
телефон и десктоп, есть светлая и тёмная темы.

## Что умеет

**Каталог и главная**
- Главная: карусель текущего сезона + недельное расписание онгоингов с числом
  эпизодов по дням.
- Каталог: мгновенный поиск с дебаунсом, фильтры по жанрам, годам, рейтингу,
  статусу и типу, сортировка, сетка/список.

**Страница аниме**
- Описание, характеристики, порядок просмотра (сиквелы и связанные тайтлы).
- Встроенный плеер с эпизодами, переключением озвучки и перевода.

**Аккаунт**
- Регистрация и вход с hCaptcha, JWT-сессии.
- Профиль: ник, привязанные аккаунты, роли.
- Списки «смотрю / запланировано / просмотрено / отложено / брошено»,
  отметка просмотренных эпизодов, избранное и статистика по статусам.

**Друзья**
- Добавление и удаление друзей, просмотр по категориям, входящие заявки.

**Игровые фишки**
- **AniMatch** — свайпер: вправо — добавить в список, влево — пропустить,
  подборка из случайных тайтлов.
- **AniTournament** — турнир с двойным выбыванием из ваших просмотренных.
- **AniTier** — тир-лист с drag-and-drop: кидайте просмотренные по тирам,
  свои цвета и названия.

## Стек

- React 19 + TypeScript + Vite
- TanStack Query + Axios (API-слой сам повторяет запрос после hCaptcha-челленджа)
- React Router v7, страницы грузятся лениво (`React.lazy`)
- Tailwind CSS 4 + shadcn/ui, светлая/тёмная темы
- Framer Motion, `@dnd-kit`, карусель Embla
- ESLint, Vitest + Testing Library
- Деплой на Netlify (есть `netlify.toml`)

## Запуск

Требуется Node.js 20+.

```sh
npm install
npm run dev        # http://localhost:5173
```

Чтобы приложение работало с API, нужен токен приложения. Скопируйте
`.env.example` в `.env` и заполните `VITE_APP_TOKEN`:

```sh
cp .env.example .env
```

`VITE_HCAPTCHA_SITE_KEY` — опционально, используется при челлендже капчи на
изменяющих запросах. Учтите: hCaptcha не работает на хосте `localhost` —
открывайте dev-сервер на `http://127.0.0.1:5173`.

### Скрипты

```sh
npm run dev          # dev-сервер
npm run build        # проверка типов + сборка в dist/
npm run lint         # ESLint
npm run test:run     # Vitest однократно
npm run preview      # предпросмотр сборки
```

### Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `VITE_APP_TOKEN` | да | Токен приложения для API YummyAnime |
| `VITE_HCAPTCHA_SITE_KEY` | нет | Site key hCaptcha для челленджа капчи |

## Структура

```
src/
├── api/            # API-клиенты (auth, anime, list, friends, users)
├── components/     # UI и фичевые компоненты (shadcn/ui в components/ui)
├── hooks/          # логика фич, отдельно от представления
├── lib/            # хелперы (даты, URL изображений, логика тиров/турнира)
├── pages/          # страницы, код-сплиттинг
├── types/          # доменные типы
└── App.tsx         # роутинг и защита маршрутов
```

Логика (hooks) намеренно отделена от UI (components) — одни и те же данные
переиспользуются в десктопной и мобильной вёрстке.

## Разработка

- `npm run lint` и `npm run test:run` должны оставаться зелёными перед PR.
- Новые запросы к API — через `src/api/`, чтобы слой ретраев капчи применялся
  единообразно.
- Страницы держите ленивыми (`React.lazy`), чтобы сохранить код-сплиттинг.
